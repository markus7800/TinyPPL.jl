## C. Inference silently returns wrong results
- [x] C1 ✅ `src/evaluation/universal/HMC.jl` — non-parametric HMC kinetic energy `Σp²` missing `/2` (N(0,1) → mean −1.6, var 8.5). Fixed together with C2 (see C2 for the other NP-HMC fixes).
- [x] C2 ✅ `src/evaluation/universal/HMC.jl` — stale addresses deleted from `X_current` (old trace, already stored in `result`) instead of `X_proposed`. NP-HMC was rewritten with plain `Dict`s; further fixes found while fixing:
  - momentum `P` shared its `Dictionaries` index with `X`, so addresses inserted during the gradient pass got an uninitialised momentum and were never added to `K`;
  - instantiated addresses were drawn from the prior at time t (implicit x0 = x_t − t·ε·p0) and `-log q(x0)` was missing from the initial energy; now x0 ~ q = N(0,1), x_t = x0 + t·ε·p0 and both `-log q(x0)` and `p0²/2` enter H(current);
  - addresses unused by the proposed trace are now scored with `-log q` in H(proposed) (extended target π(X_used) ∏ q(X_unused));
  - `x_initial` (constrained trace) is transformed to unconstrained space (was `todo(x_initial)`, part of B5).
  - pedestrian (`examples/universal_non_parametric_hmc.jl`, acceptance 0.0003): not a sampler bug. The default start (a prior sample) usually walks until distance > 10; lowering the distance below 10 adds steps, so HMC is trapped there. The example now starts from the best of 1000 LW samples with L=10, ε=0.05 (acceptance ≈ 0.6, matches LW reference); the docstring notes this, and the test suite has a pedestrian case.
- [x] C3 ✅ `src/evaluation/static/SMC.jl:121` — after last observe `log_w` unchanged but multiplied into `marginal_lik` again (≈Z²); PIMH uses this ratio. Linear-space `marginal_lik` underflows.
  - fixed: weights are accumulated in log space since the last resampling and the evidence is added once per resampling step and once at the end; static `smc`/`conditional_smc` now return the **log** evidence (like graph `smc`), PIMH accepts with the log ratio;
  - latents sampled after the last observe are now scored on return (with a custom proposal their weight Q was ignored, static analogue of C14);
  - resampling weights are computed with `normalise` (no `exp` underflow).
- [x] C4 ✅ `src/evaluation/static/HMC.jl:28` — `transform_to_constrained!` applied even when `unconstrained=false` (Gamma sample 2 → e²). Constrained HMC with default `x_initial = zeros` starts outside support.

- [x] C5 ✅ `src/graph/core/core.jl:324-329` — unconstrained logjoint passes unconstrained parent values to children (graph HMC/ADVI/BBVI with `unconstrained=true`).

  - fixed: iterate `pgm.topological_order`. In the chain test, `a` has index 1 and its parent `z` index 2, so `a` was sampled with the previous `z` (E[z] ≈ 0.03 instead of 0.44).

- [x] C9 ✅ exact: `variable_elimination.jl:59,80`, `greedy_variable_elimination.jl:259,285`, `junction_tree.jl:123,210` — disconnected factor graphs: empty-scope factors dropped / JT only walks root component (two coins: evidence 0.5 instead of 0.25).

- [x] C10 ✅ `src/graph/exact/factor_graph.jl:323` (+VE/BP/JT) — `log.(sum(exp, …))` without max shift; evidence returned linear → `-Inf`/`NaN` with many observations.

- [x] C12 `src/graph/SMC.jl:26,41` — `light_smc` returns pre-resampling weights for resampled particles; linear `marginal_lik`.

- [x] C13 `src/graph/SMC.jl:117-119` — PGAS indexes `X_ref` with observed node (BoundsError); future latents never written into `X`.

- [x] C14 `src/graph/SMC.jl:73-84` — SMC with custom proposal: latents after last observe don't update `log_w`; `propose_and_logpdf(q, (addr,X))` passes a tuple.
  - fixed: final weights and the last evidence factor are computed after all nodes are processed (`log_γ_new - log_γ - log_q`); works without observations. The tuple is intended as context `x_current` (static SMC passes `(addr, trace, addresses_to_ix)`), so only `StaticProposal`-like proposals make sense in SMC — documented, the context differs between static and graph (A-type inconsistency).
- [x] C15 ✅ `src/distributions/random_walk.jl:34,53` — truncated split-normal proposal inconsistent with its `logpdf` within 1e-3 of a bound; `var/2` halves variance for bounded proposals; `DiscreteRWProposer` `% 0` for single category.
  - fixed: `ContinuousRWProposer(lower, upper, x, var)` now returns `truncated(Normal(x, √var), lower, upper)` (the split normal with mass-proportional sides is the same distribution; no `var/2`). `DiscreteRWProposer` with a single value is a point mass. The discrete wrap-around (`% b`) is consistent with its truncated geometric `logpdf` (memorylessness); its `var/2` is a heuristic scale and unchanged.
- [x] C16 ✅ `src/evaluation/universal/ADVI.jl:31-33,76` — `rand_and_logpdf(::UniversalMeanField)` runs the model via `TraceSampler` on *unconstrained* values → universal `advi_meanfield`/`bbvi` `sample_posterior` crash for constrained parents (Gamma scale → negative σ). Also: unseen addresses filled with constrained prior draws are then transformed as if unconstrained.
  - fixed: new `UniversalMeanFieldSampler` runs the model, samples unconstrained values from q and passes `T_inv(x)` to the model; addresses without variational distribution are sampled from the prior and stored as `T(value)`. `lp` is the log density of the returned unconstrained trace (incl. prior-sampled addresses).
- [x] C17 ✅ `src/evaluation/universal/LMH.jl:88,116` — Gibbs mode applies `log|X|−log|X'|` correction and uses fixed address list (wrong for universal models).
  - fixed: the `gibbs::Bool` keyword of universal `lmh`/`rwmh` is replaced by `n_updates::Int=1`, the number of random-scan single-site updates per returned sample. Each update chooses its site uniformly from the current trace, so the `log|X|−log|X'|` correction is correct. The original sweep only makes sense if the shape of the trace does not change (static models); a sweep over the current trace's addresses would make the site selection state dependent.
- [x] C18 `src/evaluation/universal/IMCMC.jl:58-65` — missing addresses silently drawn from prior without proposal term.
  - fixed: proposed model and auxiliary traces are scored with `strict_score_trace`, which throws if the involution's trace misses an address that the model visits or contains addresses that are not visited (no sound automatic completion: the reverse move would have to drop them again).
- [x] C19 `src/graph/core/plates.jl:411-439` — plated topological sort ignores edges to/from single plate members.
  - fixed: edge endpoints are mapped to their unit (containing plate or unplated node) before the topological sort; edges within a plate are skipped. Before, a model with `x[1] -> z` failed the length assertion at compile time, and `a -> x[1]` could order the plate before `a`. Cyclic plate/node dependencies give an explicit assertion message.

## A. Inconsistent APIs
- [ ] A1 Return conventions: LW normalised (universal) vs unnormalised (static, graph, completion); SMC evidence log vs linear (static and graph `smc`/`light_smc` now log); `lmh` → traces, `imcmc` → (traces, lps), `non_parametric_hmc` → `Vector{Any}` of Dictionaries without retvals; VE → log-space unnormalised `FactorNode`, BP/JT → linear normalised `Array`. - [ ] A6 ✅ Mutation without `!`: ~~static and graph `hmc` overwrite `x_initial`~~ (fixed with C4, C5), universal `bbvi` mutates dict, ~~plated `lp_unconstrained` mutates `X`~~ (fixed with C5).
